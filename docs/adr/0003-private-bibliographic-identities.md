# Catalog owns private unresolved book identity

Keep accepted and owner-private provisional book identity in Catalog, separate from saved associations, possession and reading journeys. Previously assigning provisional identity to Library made reading an unknown book depend on a saving/ownership module. The revised ownership lets Library and Reading use the same unresolved identity independently, at the cost of Catalog explicitly handling private-data access/erasure alongside public facts.

Creating that identity does not save a Library entry, start reading or submit a public contribution. Admission/merge preserves downstream personal histories. Account deletion removes private metadata and contributor attribution/recognition while retaining independent accepted bibliographic facts. Public catalog facts and private reader records keep their distinct access/erasure rules.
