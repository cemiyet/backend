# Triage labels

Canonical roles map directly to these local `Status:` values:

| Role | Status |
| --- | --- |
| needs-triage | needs-triage |
| needs-info | needs-info |
| ready-for-agent | ready-for-agent |
| ready-for-human | ready-for-human |
| wontfix | wontfix |

Use the mapped value whenever a skill names a triage role.
